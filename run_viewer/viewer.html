What changes between exercises?

01 / Baseline

One observation, one action

The naive agent receives the mission and recent history, then returns one action. This establishes the reference performance.

Observe → choose action → execute
02 / Planning memory

Keep a plan and a subgoal

Every action call requests PLAN, SUBGOAL and ACTION. Valid memory is saved for the next step; KEEP preserves it. Memory resets per episode.

Observe + memory → update plan → act
03 / Self-reflection

Review behavior, then act

A separate critic call reviews recent transitions. Scheduled every 16 actions or triggered by possible loops, with an 8-action cooldown and at most 4 reviews per episode.

Observe → [review if triggered] → act
